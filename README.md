# CMU TARE FAR PCT Planners

Combined archive of four local planner directories:

- `cmu_exploration_go2_20260417`
- `tare_planner`
- `far_planner`
- `PCT_planner`
- `SimEnv`

The repository also includes the competition rules PDF from the local project folder.

This upload intentionally excludes nested Git metadata, generated ROS/catkin build folders, logs, Python caches, and the large `campus.dae` mesh that exceeds GitHub's normal 100 MB file limit.
